# Security

Report a vulnerability privately through GitHub's **private vulnerability reporting** on this repository (Security,
then Report a vulnerability). There is no email address for reports, on purpose. Please don't open a public issue.

In scope: this repository's workflows, scripts and settings, and anything that would let a pull request or issue
change the portfolio without a maintainer's review.

**Scams using The Flock's name:** The Flock never DMs anyone, never runs a private group and never asks for money.
If someone does in its name, it's a scam. See [docs/SCAM-SIGNS.md](docs/SCAM-SIGNS.md).
