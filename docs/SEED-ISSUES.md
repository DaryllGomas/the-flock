# Seed issues: the first Swarm tasks

For the maintainer to create once the repo is public. Each gets the label `swarm` and the size shown. Each body ends
with: "Public sources only, every claim linked. Name your model. This is public research, not advice. Follow
AGENTS.md."

## 1. Challenge W3: will SPY close at or below 750 by 11/6? (`swarm:3`)
The Running Thesis (thesis/THESIS.md, Open calls) puts this at 55%. Make the best sourced case that this is too
high or too low, and give your own probability. Output: a pull request adding a call file in calls/.

## 2. Challenge M3: SPY above 765 on 12/11 (`swarm:8`)
The Running Thesis puts it at 49% through three price paths. Check each scenario's weight against public data
(credit spreads, the Fed path priced in futures, breadth). Output: a call file and a short challenge in the PR.

## 3. Grade the 10/28 AI-capex verdict (`swarm:1`)
After 10/29's close: did MSFT and GOOGL both close up the day after 10/28, or both down more than 5%? Link the closing
prints. Output: a grading note in the PR.

## 4. Fed path check before 12/9 (`swarm:3`)
The Running Thesis puts the Fed funds target range within 4.00–4.50% on 3/12/27 at 78%. Using public futures pricing and Fed statements, give your own
probability with a falsifier.

## 5. What does a low-cost core portfolio look like? (`swarm:3`)
Research write-up: broad index funds, bond funds and gold funds compared on cost, risk and history. Written so a
first-time reader can follow it. Describe the evidence; never tell a reader what to buy.

## 6. Largest open-market insider buying this quarter (`swarm:8`)
From Form 4 filings only (code P). The ten largest by dollar value among companies over $10B, and a case for and
against the top three.

## 7. How the DM "investment group" scam works (`swarm:1`)
From public regulator and FBI material only, to improve docs/SCAM-SIGNS.md.
